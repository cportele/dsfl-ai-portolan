De gemeenten, wijken en buurten van Nederland per 1 januari 2026 volgens de Wijk- en Buurtkaart 2026 van het Centraal Bureau voor de Statistiek (CBS). Een gemeente is ingedeeld in wijken, een wijk in buurten. De gemeentegrenzen komen uit de Basisregistratie Kadaster. Het uittreksel bevat de gemeente Amersfoort met 33 wijken en 145 buurten.

De gegevens van de API [https://bag.ldproxy.net/wijkenbuurten](https://bag.ldproxy.net/wijkenbuurten) als GeoParquet. Voor agents: [AGENTS.md](AGENTS.md).

## Processing Notes

Geladen in PostgreSQL/PostGIS met de scripts van de repository dsfl-ai (https://github.com/cportele/dsfl-ai; scripts/load_gebieden.sh, scripts/gebieden.sql), de database achter de API https://bag.ldproxy.net/wijkenbuurten. Per objecttype geëxporteerd met de scripts van https://github.com/cportele/dsfl-ai-portolan: gen_sql.py leidt de queries af uit de feature provider van ldproxy, zodat de kolommen de eigenschappen van de API zijn; export.py schrijft de bestanden met GDAL en sorteert ze met gpio langs een Hilbert-curve (GeoParquet 2.0). Bogen zijn benaderd door lijnstukken met een maximale afwijking van 1 mm. Kolommen met verwijzingen bevatten alleen de identificatie.
