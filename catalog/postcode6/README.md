# Postcodegebieden 2024 (CBS)

![postcode](https://img.shields.io/badge/postcode-blue) ![statistiek](https://img.shields.io/badge/statistiek-blue) ![inwoners](https://img.shields.io/badge/inwoners-blue) ![huishoudens](https://img.shields.io/badge/huishoudens-blue) ![woningen](https://img.shields.io/badge/woningen-blue) ![CBS](https://img.shields.io/badge/CBS-blue)

Statistische gegevens per postcode (PC6) van het Centraal Bureau voor de Statistiek (CBS) op 1 januari 2024: inwoners naar geslacht, leeftijd en herkomst, particuliere huishoudens naar samenstelling en woningen naar bouwjaar, eigendom en bewoning. Elk postcodegebied (bijvoorbeeld 3811LM) is een object; in het bestand van het CBS dekken de gebieden Nederland zonder gaten, ook gebieden zonder inwoners. Bron: CBS Postcode6 2024, eerste versie (maart 2025); geboorten, WOZ-waarde, energieverbruik en de nabijheid van voorzieningen publiceert het CBS pas in een latere versie, ze ontbreken daarom. Het uittreksel bevat 3.609 postcodegebieden in gemeente 0307 en 4 daarbuiten (3851DP in gemeente 0233; 3181EM in gemeente 0599; 3818MZ in gemeente 0327; 2324VE in gemeente 0546), die adressen in de BAG van dit uittreksel hebben.

De gegevens van de API [https://bag.ldproxy.net/postcode6](https://bag.ldproxy.net/postcode6) als GeoParquet. Voor agents: [AGENTS.md](AGENTS.md).

## Processing Notes

Geladen in PostgreSQL/PostGIS met de scripts van de repository dsfl-ai (https://github.com/cportele/dsfl-ai; scripts/load_postcode6.sh, scripts/postcode6.sql), de database achter de API https://bag.ldproxy.net/postcode6. Per objecttype geëxporteerd met de scripts van https://github.com/cportele/dsfl-ai-portolan: gen_sql.py leidt de queries af uit de feature provider van ldproxy, zodat de kolommen de eigenschappen van de API zijn; export.py schrijft de bestanden met GDAL en sorteert ze met gpio langs een Hilbert-curve (GeoParquet 2.0). Bogen zijn benaderd door lijnstukken met een maximale afwijking van 1 mm. Kolommen met verwijzingen bevatten alleen de identificatie.
