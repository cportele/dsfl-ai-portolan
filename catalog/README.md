# Amersfoort: BAG, BGT en CBS-gebieden (DSFL AI)

![BAG](https://img.shields.io/badge/BAG-blue) ![BGT](https://img.shields.io/badge/BGT-blue) ![CBS](https://img.shields.io/badge/CBS-blue) ![Amersfoort](https://img.shields.io/badge/Amersfoort-blue) ![adressen](https://img.shields.io/badge/adressen-blue) ![gebouwen](https://img.shields.io/badge/gebouwen-blue) ![topografie](https://img.shields.io/badge/topografie-blue)

De gegevens achter de OGC API's op [bag.ldproxy.net](https://bag.ldproxy.net) als GeoParquet, met historie: de Basisregistratie Adressen en Gebouwen (BAG) voor de gemeente Amersfoort en de Basisregistratie Grootschalige Topografie (BGT) voor de omgeving van Amersfoort, met de gemeenten, wijken en buurten en de postcodegebieden van het CBS. Een collectie per objecttype van de API's, met dezelfde eigenschappen. Voor agents: [AGENTS.md](AGENTS.md). Elke API is ook een MCP-server; voor agents die die gebruiken is er de skill [dsfl-ai-gebouwde-omgeving](https://github.com/cportele/dsfl-ai/tree/master/skills/dsfl-ai-gebouwde-omgeving).
